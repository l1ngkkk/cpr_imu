# CPR-IMU：基于 IMU 的心肺复苏按压深度与频率检测

用一颗 6 轴 IMU（ST **LSM6DSV**）贴在按压位置上，实时解算**胸外按压的深度（行程）与频率**，通过串口输出结果；配套一套"串口回放 + 逐样本复刻"的板级验证工具链，以及和标准测试平台（压力垫 + 视频）对比的离线分析脚本。

面向 STM32F103C8（Cortex-M3，64 KB Flash / 20 KB RAM），Keil MDK + ARMCC 5.06。

## 本次更新（2026-11）

### 一、方法：新增「漏积分二次积分」深度估计算法

原来的实现把一次按压近似成正弦，用一个周期内的**基波幅值**反推位移（单频正交检测，`cpr_fit_depth`）。新方法改为**直接把竖直加速度积分两次得到位移**，再取峰谷差：

```
ω0 = 2π · 0.5 Hz                     // 泄漏频率
v += (a_vertical · 9.80665 − ω0·v) · dt      // 一次积分 → 速度
d += (v − ω0·d) · dt                          // 二次积分 → 位移
depth = K · (max d − min d)                   // 峰谷差 = 本次行程
```

- `−ω0·v`、`−ω0·d` 两个泄漏项等价于一个 0.5 Hz 高通，用来抑制加速度计零偏被积分成漂移；它**乘在状态上，不是加在结果上**，所以结果里没有任何偏置常数。
- 位移极值用「本周期累计最大/最小」来取，速度过零只负责**定时**——实测这样比用 ±15 mm/s 滞回带去判定更准（早期版本用滞回带会把峰谷各截掉一点，sim01 深度偏小 20%）。
- 标定只有一个乘法系数 `K = 0.914`，三次实验离散度 3.9%。

**为什么换**：旧方法的深度 ∝ T²（周期抖 1% 深度抖 2%）、依赖带通滤波器的通带增益、且对波形形状敏感；新方法不需要周期估计、不需要滤波器增益标定、积分本身是 1/ω² 低通天然抗高频噪声，计算量从「每周期 60 次 sin/cos + 2×2 解方程」降到「每采样 4 次乘加」。

实测（板级，三次实验，与平台行程对比）：

| 指标 | 旧方法 dft1 | 新方法 漏积分 |
|---|---|---|
| MAE | 1.78 mm | **1.71 mm** |
| RMSE | 2.48 mm | **2.15 mm** |
| 最大误差 | 7.9 mm（单次最高 12.2） | **5.5 mm** |
| 标定增益离散度 | 5.6% | **3.9%** |
| 每个周期计算量 | 60 次 sin/cos + 2×2 求解 | 4 次乘加/采样 |

两种方法在工程里**并存**：`cpr_leaky_step()` 是新方法，`cpr_fit_depth()` 是旧方法，可通过 `CPR_DEBUG_OLD` 做 A/B 对比。

### 二、修复：按压检测门限误杀（旧问题）

周期门限 `(2·half) >= 0.75·period_avg` 假设"一次按压 = 一个负半周"，但带通后的加速度并不对称（负半周实测只有 0.36~0.38 个周期），门限 0.375 正好卡在上面，导致 **63 次按压只上报 12~19 次**。放宽到 `0.55` 后计数恢复到 62/69/65，与平台一致。

### 三、修复：首次按压的频率初值

首拍没有"上一次间隔"，原代码退化成 `2·half = 0.36 s → 167 cpm`（真实 117 cpm 上下），且一阶平滑要 15~20 拍才收敛。改为用当前节奏均值（初值 0.5 s ≈ 120 cpm），**第一拍就准**。

## 算法流程

```
   I2C 读 LSM6DSV @120 Hz
            │
            ▼
   重力方向估计（一阶低通 τ=1 s）      u = a/|a| 平滑
            │
            ▼
   av = a·u − 1000 mg               竖直加速度
            │
            ├──────────────► 带通（1 Hz 高通 ×2 + 8 Hz 低通） ──► 周期/频率检测（滞回过零）
            │                                                          │
            ▼                                                          ▼
   漏积分两次 → 位移 d                                       单频正交 → 基波幅值 A
            │                                                          │
            ▼                                                          ▼
   速度过零 → 峰谷差 → depth                                  depth = 2A·g/ω²
        （新方法，K=0.914）                                    （旧方法，+13 mm 偏置）
```

**深度口径**：新方法输出的是**行程**（一个周期内的峰谷差），与前文定义的"压缩行程"一致。标准测试平台自报的 `mannequin_depth` 是从**最初静置**算起的，包含施救者手压的静息位移（实测 10~15 mm），两者相差约 12 mm，需要换算后再比较。

**频率**：由相邻两次按压的时间差反算 `60/Δt`；比基于一阶平滑的方案收敛快得多（第一拍即准）。

## 串口输出格式

**实机固件**（每次按压一行，在压到底后约 8.5 ms 输出）：

```
#12  t=7107 ms  dt=488 ms  depth= 51.0 mm  avg= 51.6 mm  rate=123 cpm
```

`depth` = 本次行程，`avg` = 最近 2 次平均，`dt` = 与上一次的间隔，`rate` = 由 `dt` 反算的频率。

**回放固件**：

```
EV,<n>,<tick>,<interval>,<depth_old>,<rate>,<数据时间ms>     # 旧方法
EVL,<n>,<数据时间ms>,<depth>,<depth_avg>                     # 新方法
```

## 已知限制

1. **绝对深度不可测**：正弦/直流位移在频域上是 0 Hz，任何高通都会把它滤掉；不做高通的二次积分在 30 s 内会漂 128~2237 mm（见 `fit_work/absint.py`）。因此「从最初静置算起的深度」只能靠一个经验常数（约 12 mm）补，且该常数随操作者手压轻重变化。
2. **与平台的口径差异**：平台自报深度含手压静息位移，比本方法输出的行程高 10~15 mm。
3. **按压频率相关**：若带通高通截止取 1 Hz，则 90 cpm 与 150 cpm 下基波增益差约 16%，会让深度随频率漂移；把截止降到 0.6~0.7 Hz 可把该差异压到 2% 以内（新方法因积分自带高通，不受此影响）。
4. 三次实验的按压频率都在 117~129 cpm，**未覆盖 90~100 cpm 与 140~150 cpm**，频率相关性还需补测。
